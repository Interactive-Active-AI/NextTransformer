## Contribute

[Choose a T3 configuration and contribute to the 2K scaling study](../../#contribute). Each configuration lists reference code and the work it still needs.

New methods, results, fixes and documentation are welcome. Start with an issue for anything larger than a fix, then
work on your fork. For a new method, open one pull request with the plugin and its audited formal result. The
[contributing guide](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CONTRIBUTING.md) has the
details, and these guides cover the common paths:

- [Add a method as a plugin](../guides/plugins/)
- [Submit a result](../guides/submit-a-result/)
- [Change shared code](../guides/changing-shared-code/)

Everyone taking part is expected to follow the
[code of conduct](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CODE_OF_CONDUCT.md). Report
security issues privately, as described in the
[security policy](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/SECURITY.md).

## Built on NextTransformer

Community projects that extend NextTransformer.

  [![NextTransformer-V: a multimodal track for NextTransformer](https://raw.githubusercontent.com/Enderfga/NextTransformer-V/8cd729800cea4ab23fdc5c083e8e2c68f2e654f7/docs/assets/banner.webp)](https://github.com/Enderfga/NextTransformer-V)

<Card title="ResearchBoost-Agent">
  [![ResearchBoost-Agent: AI that accelerates the research that advances AI](https://raw.githubusercontent.com/DAGroup-PKU/ResearchBoost-Agent/600043885d7eb3e9326725b47e966e273712dfe2/docs/assets/readme/banner-en.jpg)](https://github.com/DAGroup-PKU/ResearchBoost-Agent)

  <Badge text="Training speedups" /> by [AI4AI for Anything](https://github.com/AI4AI-for-Anything), contributed by [@henry-y](https://github.com/henry-y)

  An agent that profiles, optimizes and validates AI training code. It contributed NextTransformer's opt-in
  `--speedups` ([#26](https://github.com/Interactive-Active-AI/NextTransformer/pull/26)): fused kernels for the shell every method shares. Its `exact` mode reproduces the
  default path bit for bit, formal runs accept it, and it trains `dense_full` 1.38× faster on one eight-GPU node.
