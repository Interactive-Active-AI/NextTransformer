## Why NextTransformer

<CardGrid>
  <Card title="Frontier architectures, one framework" icon="puzzle">
    Compare dense, sparse, linear, looped, residual and hybrid architectures in one codebase. A new method is one plugin folder.
  </Card>
  <Card title="A fair, explicit protocol" icon="approve-check">
    Same data, tokens, optimizer, schedule and evaluation for every model, with training compute matched to ±1% by an
    operator-level ledger and audited over the whole run.
  </Card>
  <Card title="49B tokens of pretraining" icon="rocket">
    Train a ~1.4B-parameter model on 49B tokens on one 8-GPU node in 2–4 days. Recipes for 400B tokens and larger models
    arrive in November 2026.
  </Card>
  <Card title="Agent-native research" icon="star">
    Hand the arena task to your agent and let it research the next architecture. The full agent-native version ships by
    November 14, 2026.
  </Card>
</CardGrid>
