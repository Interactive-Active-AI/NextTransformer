## 为什么选择 NextTransformer

<CardGrid>
  <Card title="一个框架，集成前沿架构" icon="puzzle">
    在同一套代码中比较完整注意力、残差连接、线性与稀疏注意力、循环计算和混合架构。新方法只需一个插件目录。
  </Card>
  <Card title="公平、明确的协议" icon="approve-check">
    每个模型使用相同的数据、token、优化器、调度和评测；训练算力由算子级账本对齐到 ±1% 以内，并对整个运行做累计审计。
  </Card>
  <Card title="49B tokens 预训练" icon="rocket">
    在一台 8 卡机器上，2–4 天即可用 49B tokens 训练约 1.4B 参数的模型。400B tokens 和更大模型的配方将于 2026 年 11 月补齐。
  </Card>
  <Card title="Agent 原生研究" icon="star">
    把竞技场任务交给你的 agent，让它研究出下一代架构。完整的 agent 原生版本将于 2026 年 11 月 14 日前上线。
  </Card>
</CardGrid>
