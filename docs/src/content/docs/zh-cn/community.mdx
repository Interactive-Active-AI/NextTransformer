## 参与贡献

在[网站 Contribute 入口选择 T3 配置](../../../#contribute)，可以找到每个家族的参考代码，以及该配置还需要的实现、核算或训练工作。

欢迎贡献新方法、结果、修复和文档。比修复更大的改动请先开 issue，然后在你的 fork 上开发。新方法须在取得正式结果并通过审计后，将插件和结果放在同一个 PR 中提交。
详见[贡献指南](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CONTRIBUTING.md)，常见路径见：

- [以插件形式添加方法](../guides/plugins/)
- [提交结果](../guides/submit-a-result/)
- [修改共享代码](../guides/changing-shared-code/)

所有参与者都应遵守[行为准则](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/CODE_OF_CONDUCT.md)。安全问题请按[安全策略](https://github.com/Interactive-Active-AI/NextTransformer/blob/main/SECURITY.md)私下报告。

## 基于 NextTransformer 的项目

扩展 NextTransformer 的社区项目。

<Card title="NextTransformer-V">
  [![NextTransformer-V：NextTransformer 的多模态版本](https://raw.githubusercontent.com/Enderfga/NextTransformer-V/8cd729800cea4ab23fdc5c083e8e2c68f2e654f7/docs/assets/banner.webp)](https://github.com/Enderfga/NextTransformer-V)

  <Badge text="多模态" /> 作者 [@Enderfga](https://github.com/Enderfga)

  冻结的 SigLIP2 图像 token 与文本交错排进 8,192 长度的上下文，NextTransformer 的每种方法都不用改动就能直接训练，训练算力对齐到 1% 以内。第一项研究经过预注册，探讨混合架构从哪里读取图像的二维布局。

  <LinkButton href="https://github.com/Enderfga/NextTransformer-V" variant="secondary" icon="github" iconPlacement="start">在 GitHub 上查看</LinkButton>
</Card>

<Card title="ResearchBoost-Agent">
  [![ResearchBoost-Agent：用 AI 加速推动 AI 进步的研究](https://raw.githubusercontent.com/DAGroup-PKU/ResearchBoost-Agent/600043885d7eb3e9326725b47e966e273712dfe2/docs/assets/readme/banner-zh.jpg)](https://github.com/DAGroup-PKU/ResearchBoost-Agent)

  <Badge text="训练加速" /> 作者 [AI4AI for Anything](https://github.com/AI4AI-for-Anything)，贡献者 [@henry-y](https://github.com/henry-y)

  自动分析、优化并验证 AI 训练代码的 agent。它为 NextTransformer 贡献了可选的 `--speedups`（[#26](https://github.com/Interactive-Active-AI/NextTransformer/pull/26)），把所有方法共用的外壳融合成更少的 kernel。其中 `exact` 模式与默认路径逐位一致，可用于正式运行，在单机 8 卡上把 `dense_full` 的训练提速 1.38 倍。

  <LinkButton href="https://github.com/DAGroup-PKU/ResearchBoost-Agent" variant="secondary" icon="github" iconPlacement="start">在 GitHub 上查看</LinkButton>
</Card>
