# Security policy

Please do not report security issues in public issues, discussions or chat.

Report them privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**. Include what you found, how to reproduce it, and its impact. We aim to acknowledge
reports within a week and will coordinate a fix and its disclosure with you.

In scope: the Python package, the command-line tools, the GitHub Actions workflows, and the website and
documentation builds in this repository. Issues in third-party dependencies should go to their maintainers; tell
us as well if NextTransformer's use of them is affected.

Never commit credentials, tokens, private data or checkpoints that you are not allowed to share. If you notice
such content in the repository, report it the same way.
